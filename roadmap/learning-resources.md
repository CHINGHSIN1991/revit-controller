## Revit API

| 資源 | 何時讀 |
| --- | --- |
| Revit API 官方說明檔（隨 Revit SDK 附的 `RevitAPI.chm`） | 隨時查詢；以**實際安裝的版本**為準 |
| [revitapidocs.com](https://www.revitapidocs.com/) | 線上查 API，可切換版本比較差異 |
| Revit SDK 的 Samples 資料夾 | Day 3（ExternalEvent 範例）、Day 12（視圖）、Day 24（Dockable Pane） |

| The Building Coder 部落格（Jeremy Tammik） | 遇到幾何、Boolean 運算、連結模型等疑難時搜尋 |
| Autodesk Revit API 論壇 | 卡關時搜尋 |
| [Nice3point/RevitTemplates](https://github.com/Nice3point/RevitTemplates) | Day 2，參考多版本 build 的做法 |
